# Roadmap

Ideas carried over from an earlier Vite/React version of this project that this
version does not have yet:

- Inventory management (stock levels per menu item)
- Customer management (repeat customers, contact list)
- Richer reports: peak hours, most active tables, weekly and monthly totals
- Phone verification of customers
- Real server-side authorisation (Supabase Auth plus row-level security for
  staff roles), replacing the shared-password gate described in the README
